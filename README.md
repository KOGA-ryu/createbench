# Create Bench

Create Bench is a deterministic UI layout builder designed to eliminate ambiguity between human intent and generated code.

## Core Features

- Schema-driven UI definition
- Visual layout editor (canvas)
- Inspector-based property editing
- Checklist validation system
- Deterministic DSL + JSON export
- Template-based layout creation
- Project save/load

## Running

```bash
python createbench/run_app.py
```

## Export

* DSL output for AI interaction
* JSON output for tooling

Export is blocked if checklist errors exist.

## Philosophy

* No guessing
* No hidden logic
* Deterministic outputs
* Explicit state
